Salesforce Custom Skill Suite

Purpose-built Claude Code skills, agents, and hooks covering Salesforce documentation, audits, diagnostics, and health checks.

bounteous-sfdc plugin

Skills

Reusable Claude Code skills, triggered by natural-language requests or slash commands, that generate reports, audits, and documentation directly from a Salesforce org or local metadata.

Dependency Analyzer

Published

Maps every reference to a field, class, trigger, flow, or object, and traces transitive dependency chains across the org.

Use cases
  • ✓Blast-radius check before deleting or refactoring
  • ✓Find every place a field or class is used
  • ✓Plan a safe removal order for legacy metadata

Object Blueprint

Published

Generates an interactive 8-tab HTML blueprint of any object — health score, fields, automation, layouts, and relationships.

Use cases
  • ✓A 360° view of an object — fields, automation, layouts, and relationships in one place
  • ✓Onboard a new admin or developer to an object
  • ✓Audit an object's health before a redesign

Org Documentation

Published

Generates documentation for Apex classes, Apex triggers, and Flows across the org.

Use cases
  • ✓Keep technical docs current after every release
  • ✓Hand off a documented org to a new team
  • ✓Prep for an internal or client audit

Release Notes Summarizer

Published

Turns a given Salesforce release notes PDF into a plain-English summary of new features, retirements, and auto-enabled changes. Today it summarizes the release itself — org-specific impact analysis is on the roadmap.

Use cases
  • ✓Quickly digest a release before it lands
  • ✓Spot features retiring or auto-enabling
  • ✓Brief stakeholders on what's changing

Unused VF Pages

Published

Finds Visualforce pages with zero references anywhere in the org.

Use cases
  • ✓Clean up legacy metadata before a migration
  • ✓Confirm a page is safe to delete
  • ✓Org health audit ahead of a release

Cloud Footprint Audit

Published

Use cases
  • ✓License renewal or cost-optimization review

Access Diagnostics

Published

Walks Salesforce's full access-resolution hierarchy to explain why a user can or can't see a record, object, or field.

Use cases
  • ✓Resolve a "why can't this user see this" ticket
  • ✓Explain how a user is able to see a record they shouldn't
  • ✓Trace sharing rules and role hierarchy fast

Debug Log Analyzer

Turns a raw Apex debug log or stack trace into a plain-English root-cause report with a proposed code fix.

Use cases
  • ✓Triage a failing trigger or flow in production
  • ✓Get a code-specific fix, not just the error

Formula Analyzer

Audits formula fields for complexity and best practices, with concrete before/after refactor suggestions.

Use cases

Automation Health Analyzer

Published

Flags objects with risky automation — conflicting Flows/Triggers firing on the same record, missing recursion guards — and hands you a ready-to-assign ticket for each fix.

Use cases
  • ✓Find exactly which objects have risky or conflicting automation
  • ✓Prioritize refactoring effort instead of guessing from a complexity score
  • ✓Generate a ready-to-assign ticket for each automation fix

Batch/Async Job Health Monitor

Published

Surfaces batch and async jobs that are silently failing or stuck, and flags scheduled jobs that collide or hit concurrency limits.

Use cases
  • ✓Catch silently failing or stuck jobs before they cause a discrepancy
  • ✓Spot colliding scheduled jobs and concurrency-limit conflicts
  • ✓Fix data-sync gaps before they become business-impacting

API Version Drift Report

Published

Identifies which specific components will actually break — not just look outdated — if an API version is bumped, and which integrations face a real retirement deadline.

Use cases
  • ✓Plan a safe API version-bump sequence
  • ✓Identify integrations facing a real retirement deadline

Published

Classifies every Custom Setting as Ready / Review / Keep as-is / Not Migratable / Delete Candidate, with a capacity check upfront and a risk-ordered migration plan.

Use cases

Reports/Dashboards Bloat Analyzer

Published

Scores every report and dashboard for staleness, broken references, and orphaned ownership, then produces a risk-ordered cleanup plan with a 30-day recoverable staging policy.

Use cases
  • ✓Clean up report/dashboard bloat without breaking a live page
  • ✓Catch reports owned by a deactivated user before deleting
  • ✓Confirm what's truly unused vs. embedded elsewhere

Code Scanner

Published

Runs Salesforce Code Analyzer (PMD, ESLint, RetireJS, Flow Scanner, and more) against the project and writes every violation to an Excel report.

Use cases
  • ✓Baseline code quality before a release

Use cases

Agents

Standalone orchestrator agents that coordinate multiple skills into a single end-to-end pipeline, invoked directly or by name.

Org Health Check Orchestrator

Published
Also known as Agent IrisTools: Bash, Read, Write, Edit, Glob, Grep, AskUserQuestion, Agent

End-to-end Org Health Check pipeline agent. Runs the Extractor, Code Scanner, and Coverage Extractor, invokes four enrichment skills (Cloud Footprint, Object Blueprint, Integration Health Monitor, Debug Log Analyzer), then generates the Health Check Word doc and the standalone HTML executive report.

Use cases
  • ✓Run a full org health check with a single request — "how is the health of my org"
  • ✓Coordinate 7+ skills into one client-deliverable pipeline
  • ✓Save hours of manual report assembly per engagement

Hooks

PreToolUse guardrails that run automatically before matching tool calls (Bash | PowerShell | mcp__salesforce__deploy_metadata) — no invocation needed, they're always active for anyone using the plugin.

Deploy Block Guard

PreToolUse

Blocks any Salesforce deploy command or the deploy_metadata MCP tool outright. This suite is a read-only metadata/health-check toolset by design — there is nothing in scope to deploy.

Use cases
  • ✓Prevent an accidental sf project deploy start mid-session
  • ✓Block the deploy_metadata MCP tool unconditionally
  • ✓Keep every skill in the suite strictly read-only

force-app Protect Guard

PreToolUse

Blocks any Bash/PowerShell command that would delete files under force-app/ — treated as read-only reference metadata, never something to prune or clean up.

Use cases
  • ✓Stop an accidental rm -rf force-app/... mid-session
  • ✓Protect retrieved metadata from being pruned
  • ✓Enforce read-only handling of local SFDX source

Commands

Quick slash commands for everyday Salesforce CLI session checks — no metadata retrieval, just fast answers about the connected org.

/sf-whoami

Published

Shows the current default org session, all authenticated orgs, connection health warnings, and quick-action CLI commands.

/sf-trace

Published

Sets an active trace flag for a Salesforce user with sensible default log levels, valid for 6 hours; offers to extend an existing flag.

/sf-api-status

Published

Compares the project's configured Salesforce API version against the true latest version supported by the connected org, and flags if an upgrade is needed.
